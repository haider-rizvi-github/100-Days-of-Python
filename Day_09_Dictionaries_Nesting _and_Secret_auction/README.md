# Day 9 - Dictionaries, Nesting, and Secret Auction

This folder introduces dictionaries, nested data structures, and a simple auction program.

## Files

- Python_dictionaries.py: basic dictionary examples
- Nested_lists_and_dictionaries.py: nested data structure examples
- Grading_program_using_dictionaries.py: a grading example using dictionaries
- Secret_auction.py: a console-based secret auction app
- art.py: ASCII art for the auction program

## How to Run

Open a terminal in this folder and run:

```bash
python3 Python_dictionaries.py
python3 Grading_program_using_dictionaries.py
python3 Secret_auction.py
```

## What You Will Learn

- Storing and retrieving data with dictionaries
- Working with nested lists and dictionaries
- Building small interactive applications with structured data
