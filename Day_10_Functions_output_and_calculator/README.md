# Day 10 - Functions with Outputs and Calculator

This folder focuses on functions that return values, simple program flow, and building a calculator-style application.

## Files

- Calculator.py: the main calculator program
- Functions_with_outputs.py: examples of functions returning outputs
- calculator_operations.py: calculator operation logic
- leap_year.py: leap year checking example
- art.py: ASCII art used by the programs

## How to Run

Open a terminal in this folder and run:

```bash
python3 Calculator.py
python3 Functions_with_outputs.py
python3 leap_year.py
```

## What You Will Learn

- Writing functions that return values
- Organizing code into reusable modules
- Building interactive programs with clear logic
