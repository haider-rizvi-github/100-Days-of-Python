# Day 12: Scope and Number Guessing Game

This folder contains exercises focused on Python scope, constants, and building a simple number guessing game.

## Topics Covered

- Local vs global scope
- Python constants
- Function-based game logic
- User input and basic game flow

## Files

- Number_Guessing_Game.py: a simple interactive guessing game
- global_&_local_vairables.py: examples demonstrating local and global variables
- prime_number_checked.py: a script for checking whether a number is prime
- Python_constants_&_Global_Scopes.py: examples related to constants and scope
- ascii_art.py: ASCII art used in the game

## How to Run

Run any script with Python 3:

```bash
python3 Day_12_Scope_&_Number_Guessing_Game/Number_Guessing_Game.py
```

## Learning Goal

By the end of this day, you should understand how scope works in Python and how to structure simple interactive programs.
