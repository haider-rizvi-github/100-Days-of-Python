# Day 11 - Blackjack Capstone Project

## Overview

Day 11 focuses on building a complete Blackjack game as a capstone project. This project brings together several Python concepts, including functions, loops, conditionals, lists, and user interaction.

## What You Will Learn

- Creating a playable game from scratch
- Using functions to organize game logic
- Implementing game rules for Blackjack
- Handling user input and game flow
- Working with ASCII art and simple UI output

## Files

- `art.py` - Contains the ASCII art used in the game
- `Black_jack_functions.py` - Stores the helper functions for gameplay
- `Black_jack_main.py` - Main script that runs the game

## Project Goal

Build a simple command-line Blackjack game where the player can play against the computer dealer and try to get as close to 21 as possible without going over.

## Concepts Practiced

- Functions
- Loops
- Conditionals
- Lists and card handling
- User interaction in the terminal

## How to Run

Run the main file with:

```bash
python Black_jack_main.py
```

## Notes

This project is a great way to combine everything learned so far into one complete application.
