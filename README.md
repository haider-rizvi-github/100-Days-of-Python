# 100 Days of Python

This repository contains beginner-friendly Python exercises from the "100 Days of Python" learning challenge. Each folder focuses on a different topic and builds practical programming skills step by step.

## Project Structure

- Day 1 Beginner: basic printing, variables, and user input
- Day 2 Data Types and String Manipulation: strings, numbers, conversions, and calculations
- Day 3 Control Flow and Logical Operators: conditionals and decision-making
- Day 4 Randomisation and Python Lists: random values and list operations
- Day 5 Loops: for loops, while loops, and repetition
- Day 6 Functions and Karel: functions and problem-solving
- Day 7 Hangman: game logic and string handling
- Day 8 Cipher Input Functions: functions with inputs and Caesar cipher
- Day 9 Dictionaries, Nesting, and Secret Auction: dictionaries and nested data
- Day 10 Functions Output and Calculator: functions returning values and a calculator app

## How to Use

1. Open any day folder.
2. Run a Python script with Python 3.
3. Read the code carefully and try modifying it to learn faster.

Example:

```bash
python3 Day_1_Beginner/band_name_generator.py
```

## Notes

- Python 3 is recommended.
- These files are intended for learning and practice.
- Feel free to experiment and build on the examples.
