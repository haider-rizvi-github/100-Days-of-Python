# 100 Days of Python

This repository contains beginner-friendly Python exercises from the "100 Days of Python" learning challenge. It is designed to help you build practical Python skills by working through small projects and daily coding exercises.

## What You Will Learn

This journey covers the fundamentals of Python, including:

- Variables, input, and output
- Data types and string manipulation
- Conditional logic and control flow
- Randomization and lists
- Loops and repetition
- Functions and reusable code
- Dictionaries and nested data structures
- Error handling and problem-solving
- Small game and project development

## Project Structure

- Day 01 Beginner: basic printing, variables, and user input
- Day 02 Data Types and String Manipulation: strings, numbers, conversions, and calculations
- Day 03 Control Flow and Logical Operators: conditionals and decision-making
- Day 04 Randomisation and Python Lists: random values and list operations
- Day 05 Loops: for loops, while loops, and repetition
- Day 06 Functions and Karel: functions and problem-solving
- Day 07 Hangman: game logic and string handling
- Day 08 Cipher Input Functions: functions with inputs and Caesar cipher
- Day 09 Dictionaries, Nesting, and Secret Auction: dictionaries and nested data
- Day 10 Functions Output and Calculator: functions returning values and a calculator app
- Day 11 Blackjack Capstone Project: building a small game project
- Day 12 Scope and Number Guessing Game: scope, constants, and interactive gameplay

## Getting Started

1. Make sure Python 3 is installed on your system.
2. Open the repository folder in your terminal.
3. Run any Python script you want to explore.

Example:

```bash
python3 Day_01_Beginner/band_name_generator.py
```

## Recommended Workflow

- Read the code carefully before running it.
- Try to understand what each line does.
- Modify the scripts to experiment with new ideas.
- Build your own versions after completing each exercise.

## Notes

- Python 3 is recommended.
- These files are intended for learning and practice.
- Feel free to experiment and improve the examples.
- A virtual environment is helpful if you want to keep dependencies organized.
