# Day 6 - Functions and Karel

This folder introduces functions and simple problem-solving through the Karel robot exercises.

## Files

- Functions.py: basic examples of Python functions
- Reeborg_maze_escape.py: a maze-solving challenge designed for the Reeborg environment

## How to Run

- The Karel script is intended for the Reeborg world environment.
- Open the Reeborg website or platform and run the script there.

## What You Will Learn

- Defining and calling functions
- Breaking problems into smaller steps
- Thinking logically to solve simple automation tasks
