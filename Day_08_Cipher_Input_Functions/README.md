# Day 8 - Cipher, Input, and Functions

This folder covers functions with inputs and a Caesar cipher project for encryption and decryption.

## Files

- Functions_with_inputs.py: practice with function parameters and inputs
- ceasar.py: a simple Caesar cipher program
- ceasar_cipher_encryption.py: encryption logic
- ceasar_cipher_decryption.py: decryption logic

## How to Run

Open a terminal in this folder and run:

```bash
python3 ceasar.py
python3 Functions_with_inputs.py
```

## What You Will Learn

- Writing functions that take input values
- Building small command-line tools
- Implementing encryption and decryption logic
